# Frontend

The React + Vite frontend for **AI Mock Interview**.

For complete project setup, environment variables, and backend/database requirements, see the [project README](../../README.md).

## Development

From this directory:

```bash
npm ci
npm run dev
```

The frontend expects the backend API at `http://localhost:8000/api`. Start the backend separately from `../`.

## Other commands

```bash
npm run build
npm run preview
npm run lint
```
